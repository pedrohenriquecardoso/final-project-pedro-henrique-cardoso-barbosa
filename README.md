# Introduction 📜

This is my final project for Harvard's CS50 course. The project is a task management application built using C. With this application, you can perform CRUD operations on tasks and generate a TXT file to manage them. 

## Installation ☕️

1. Clone the repository.

    ```sh
    git clone https://github.com/pedrohenriquecardoso/final-project-pedro-henrique-cardoso-barbosa.git
    ```
2. Navigate to the project directory.

    ```sh
    cd final-project-pedro-henrique-cardoso-barbosa
    ```
    
3. If you are using VsCode install the C/C++ Extension Pack.

4. Open the existing project in Visual Studio Code and simply select the play button at the top right corner. Then click on the 'run C/C++ file' button.
